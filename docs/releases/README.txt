  https://dotnet.microsoft.com/en-us/download/dotnet/10.0

USE
1. Start your existing HTTP proxy.
2. Select a tool, enter its proxy host and port, and use Test connection / Set proxy.
3. For a launch profile, use Open terminal or Launch application.
4. For multiple tools, use Batch set and check the tools you want.

Reset restores the state before the first Set. Existing processes must be restarted.
Windows / User environment settings have a shared scope. WinHTTP needs Administrator.
An HTTP proxy is required. This app does not provide a VPN or proxy server.
