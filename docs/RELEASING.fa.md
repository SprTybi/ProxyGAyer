# انتشار ProxyGAyer v1.0.0

1. [فرم ساخت ریلیز](https://github.com/SprTybi/ProxyGAyer/releases/new) را باز کن.
2. تگ جدید `v1.0.0` را بساز و شاخهٔ `master` را انتخاب کن.
3. عنوان را `ProxyGAyer v1.0.0` بگذار.
4. متن [یادداشت انتشار](releases/v1.0.0.md) را در توضیحات کپی کن.
5. فایل‌های زیر را در قسمت پیوست‌های ریلیز بارگذاری کن و دکمهٔ **Publish release** را بزن.

| فایل پیوست | کاربرد |
| --- | --- |
| `ProxyGAyer-v1.0.0-standalone-win-x64.exe` | یک فایل مستقل؛ بدون نصب .NET یا DLL کنار آن |
| `ProxyGAyer-v1.0.0-win-x64.exe` | نسخهٔ سبک؛ نیازمند .NET 10 Desktop Runtime |
| `ProxyGAyer-v1.0.0-win-x64.zip` | نسخهٔ سبک همراه راهنمای کوتاه و مجوز |
| `SHA256SUMS.txt` | هش فایل‌ها برای بررسی دانلود |

نسخهٔ Standalone بزرگ‌تر است، چون .NET داخل آن قرار دارد. کاربران این نسخه فقط همان EXE را دانلود و اجرا می‌کنند. فایل‌های خودکار **Source code** در GitHub جای فایل اجرایی را نمی‌گیرند.

فایل‌های آمادهٔ بارگذاری در پوشهٔ محلی `artifacts/releases/v1.0.0` قرار دارند. قبل از انتشار، مطمئن شو آخرین سورس موردنظر روی `master` پوش شده است.
